errpath for Go

Step through the error paths errpath finds in a Go function, two ways: as a flowchart where you choose each step, and as a state machine you can send events to. On a phone, tap the expand button to view a chart full screen.

Before: PlaceOrder

Each call whose error is checked and returned is a step with two ways out: ok carries on, err leaves with the error it returns. Follow a path to CardDeclined, or all the way to Success.

Flowchart

Start at the top, then click a highlighted step to choose where the function goes next.

After a one-line pull request

The PR stops checking the confirmation email's error:

-	if err := SendConfirmation(receipt); err != nil {
-		return Receipt{}, err
-	}
+	_ = SendConfirmation(receipt)

Take the ok path past SaveOrder and watch a failed email reach Success without a trace. EmailError is gone.
